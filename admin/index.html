Kết nối GitHub

Trang admin lưu dữ liệu trực tiếp vào repo . Cần một Personal Access Token có quyền ghi (Contents: Read and write) cho repo này. Tạo tại github.com/settings/personal-access-tokens/new → Repository access: chọn đúng repo → Permissions → Contents: Read and write.

Chỉ cần làm một lần: dán token rồi bấm Lưu token. Token được mã hoá bằng mật khẩu admin và lưu lên web, từ đó mọi máy/điện thoại chỉ cần đăng nhập tài khoản/mật khẩu là dùng được. Tab này sẽ tự ẩn khi đã xong.

Danh mục sản phẩm

Mỗi danh mục là một trang trong pageview và một ô ở dải danh mục trên web. Thứ tự ở đây là thứ tự hiển thị. Bấm vào tên danh mục để xem và quản lý sản phẩm bên trong.

Sản phẩm

Để trống giá bán thì web hiển thị chữ “Liên hệ”. Bấm vào tên sản phẩm để sửa.

Bảng giá vàng

Nhập tay toàn bộ. Ví dụ 14560 sẽ hiển thị là 14.560. Web tự vẽ mũi tên tăng/giảm bằng cách so giá hôm nay với hôm qua. Khi bạn lưu vào ngày mới, giá hôm nay hiện tại tự chuyển sang cột hôm qua, bạn chỉ cần nhập giá mới. Tích Tại tiệm để tô vàng dòng đó.
