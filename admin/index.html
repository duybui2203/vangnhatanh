Kết nối GitHub

Trang admin lưu dữ liệu trực tiếp vào repo . Cần một Personal Access Token có quyền ghi (Contents: Read and write) cho repo này. Tạo tại github.com/settings/personal-access-tokens/new → Repository access: chọn đúng repo → Permissions → Contents: Read and write.

Cách dùng đơn giản nhất: dán token một lần rồi bấm “Lưu lên web”. Token được mã hoá bằng mật khẩu admin và lưu vào repo dữ liệu. Từ đó, trên bất kỳ máy nào bạn chỉ cần đăng nhập tài khoản/mật khẩu là dùng được, không phải nhập token nữa.

Giá Vàng Nhật Anh (nghìn đồng/lượng)

Ví dụ 147.000 nghìn đồng/lượng = 147.000.000 ₫/lượng. Khi lưu sang ngày mới, giá cũ tự chuyển sang cột “Hôm qua”. Các dòng còn lại trong bảng (SJC, DOJI, BTMC…) được bot tự cập nhật mỗi 15 phút.
